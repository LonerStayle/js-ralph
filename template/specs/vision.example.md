# vision: Bookshelf (예시 — React + FastAPI + Postgres)

> 이 파일은 **예시**입니다. onboarding 인터뷰가 `specs/vision.md` 를 자동 합성합니다.
> 직접 작성하고 싶으면 이 파일을 `vision.md` 로 복사한 뒤 내용을 갈아끼우십시오.

---

## 1. 비전
취미 독서가가 읽은 책과 메모를 한 곳에 모아 두는 가장 가벼운 개인 서가 앱.

## 2. 대상 사용자
한 달 1~5권 읽는 직장인. 평점·태그·짧은 감상을 남기고, 1년 뒤 자기 독서 흐름을 돌아보고 싶어한다. SNS 공유는 원하지 않는다.

## 3. 핵심 산출물
1. 책 추가/수정/삭제 (제목·저자·평점·감상·태그)
2. 목록 화면 (정렬: 최근 추가순 / 평점순 / 제목순)
3. 연도별 통계 화면 (권수·평균 평점·태그 분포)

## 4. 성공 정의
- 정량: 책 1권 추가 ≤ 30초, 목록 화면 1차 렌더 ≤ 500ms (책 200권 기준), 통계 화면 정확도 100%
- 정성: "공유·소셜·추천" 기능 없이도 사용자가 매주 1회 이상 자발적으로 들어오는가

## 5. 금지 / 범위 밖
- 외부 도서 DB (ISBN 자동 조회) 연동 금지 — 사용자가 직접 입력
- 다중 사용자 / 소셜 / 추천 시스템 금지
- 모바일 앱 빌드 금지 (반응형 웹만)

## 6. 외부 의존
- 외부 API: 없음
- 데이터: 사용자 입력만
- 인증: 단일 사용자 가정 (로컬 / 본인 서버 배포). 로그인 화면 없음

## 7. 규모·일정·비용 cap
- cycles ≤ 8
- 호스팅 월 $10 이하
- 단일 개발자가 이해 가능한 코드량 (백엔드 ≤ 2,000 LOC, 프론트 ≤ 3,000 LOC)

## 8. 기술 스택
디폴트:
- Backend: Python + uv + FastAPI + SQLAlchemy
- Frontend: React (Vite + TypeScript)
- DB: Postgres
- 배포: Docker compose (단일 호스트)

추가 결정:
- 상태 관리: React Query (서버 상태) + zustand (UI 상태 최소화)
- 스타일: Tailwind CSS
- 폼: react-hook-form + zod
